# Preset Win/Mac & Linux

## Windows / Mac

Use Arturias Midi Control Center and import this preset file on your Arturia Minilab mk3 or Minilab 37

- Midi Control Center https://www.arturia.com/support/downloads-manuals/product/mccu


## Linux

On Linux you have to do it manually, do to the lack of Arturias Linux support.

There is a LibreOffice Document with all the details regarding the Sysex Controls and Generic Flexi settings. How you should configure it, when using my Generic Flexi Script.
