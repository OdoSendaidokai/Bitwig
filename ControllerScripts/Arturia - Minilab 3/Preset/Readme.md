# Preset Win/Mac & Linux

## Windows / Mac

Use Arturias Midi Control Center and import this preset file on your Arturia Minilab mk3 or Minilab 37

- Midi Control Center https://www.arturia.com/support/downloads-manuals/product/mccu
- The Preset - File :  [Arturia Minilab 3 Software Preset for Midi Control Center_Colognialist_20260617.minilab3](https://github.com/OdoSendaidokai/Bitwig/blob/main/ControllerScripts/Arturia%20-%20Minilab%203/Preset/Arturia%20Minilab%203%20Software%20Preset%20for%20Midi%20Control%20Center_Colognialist_20260617.minilab3)


## Linux

On Linux you have to do it manually, due to the lack of Arturias "we consider ..." Linux support.

There is a LibreOffice Document with all the details regarding the Sysex Controls and Generic Flexi settings. How you should configure it, when using my Generic Flexi Script.

[Arturial MiniLab 3 Functions_LibreOffice_LibreCalc.ods](https://github.com/OdoSendaidokai/Bitwig/blob/main/ControllerScripts/Arturia%20-%20Minilab%203/Preset/Arturial%20MiniLab%203%20Functions_LibreOffice_LibreCalc.ods)

Here is the screenshot, if you just want to configure with Sysex Controls and you are not interested in more details.
Just make sure the knobs, faders and pads all have the same CC Numbers like on the pink marked fields.

![Screenshot to configure Sysexcontrols](https://github.com/OdoSendaidokai/Bitwig/blob/main/ControllerScripts/Arturia%20-%20Minilab%203/Preset/Arturia%20Minilab%20mk3%20%26%2037_Sysex%20Controls%20Configuration.png)
